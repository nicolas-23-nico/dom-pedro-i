# Imagens do Site

As imagens do site usam placeholders de alta qualidade do Unsplash para demonstração.

## Substituindo as imagens

Para usar suas próprias imagens:
1. Adicione suas fotos nesta pasta
2. Mantenha os mesmos nomes dos arquivos
3. Ou atualize os caminhos no index.html
