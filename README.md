# E.E Dom Pedro I - Site Oficial

Site institucional da Escola Estadual Dom Pedro I, localizada em São Miguel Paulista, São Paulo.

## 🎯 Sobre o Projeto

Este site foi desenvolvido para apresentar a escola, seus níveis de ensino e facilitar a comunicação com a comunidade. O design é moderno, responsivo e focado em uma experiência de usuário agradável.

## 📚 Níveis de Ensino

- **Centro de Estudos de Línguas (CEL)**: Desenvolvimento de línguas estrangeiras
- **Ensino Médio**: Preparação acadêmica e profissional
- **Ensino Técnico**: Formação profissionalizante

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica
- **CSS3**: Design moderno e responsivo
- **JavaScript**: Interatividade e funcionalidades
- **Google Fonts**: Tipografia (DM Sans e Manrope)

## 🚀 Como Utilizar

### Visualizar Localmente

1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` em seu navegador
3. Ou use um servidor local:
   ```bash
   # Com Python
   python -m http.server 8000

   # Com Node.js (http-server)
   npx http-server
   ```

### Personalizar o Site

#### Imagens
- Substitua as imagens na pasta `imagens/` por fotos reais da escola
- Mantenha os mesmos nomes dos arquivos ou atualize os caminhos no `index.html`

#### Contato
- Configure o número de WhatsApp no arquivo `script.js` (linha 95)
- Conecte o formulário a um serviço de envio de emails

#### Conteúdo
- Edite o texto no arquivo `index.html` conforme necessário
- Atualize os dados de contato e endereço

## 📱 Responsividade

O site é totalmente responsivo e se adapta a:
- Desktops
- Tablets
- Smartphones

## 🌐 GitHub Pages

Este site está configurado para ser publicado no GitHub Pages. Para publicar:

1. Crie um repositório no GitHub
2. Faça upload dos arquivos
3. Vá em Settings > Pages
4. Selecione a branch `main` ou `master`
5. O site estará disponível em `https://seu-usuario.github.io/nome-do-repositorio`
